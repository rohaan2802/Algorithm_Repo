## Course Overview

Design and Analysis of Algorithms (CS-2009) at FAST-NUCES Islamabad, Fall 2025. The repository has 22 lectures, three assignments with my C++ solutions, the Merkle tree, treap and heap project, past papers, practice problems, two textbooks and my study notes.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Analysis** | Asymptotic notation, recurrences, recursion trees and the master method. |
| **Unit 2 – Sorting** | Insertion, merge, quick and heap sort, and counting and radix sort in linear time. |
| **Unit 3 – Strings & graphs** | Naïve, Rabin–Karp, automata and KMP matching; BFS, DFS, MST, Dijkstra, Bellman–Ford, Floyd–Warshall. |
| **Unit 4 – Greedy & DP** | Activity selection, Huffman codes, matrix-chain, 0/1 knapsack, rod cutting and LCS. |

## Running the Code

```bash
git clone https://github.com/rohaan2802/Algorithm_Repo.git
cd Algorithm_Repo
g++ -std=c++17 -O2 "Assignments/22i_2327_A3_Sec_D/Q_01_Sol/Source.cpp" -o q1
./q1
```

- **Visual Studio:** open any `.sln` file (for example `Assignments/22i_2327_A3_Sec_D/Q_01_Sol/Q_01_Sol.sln` or `Practice Problems/String_Matching_Program/Project1.sln`) with the *Desktop development with C++* workload and press **Ctrl+F5**.
- **Other compilers:** each project is a single `Source.cpp`, so `g++` or `clang++` builds it directly.
- Build folders (`.vs`, `x64`, `Debug`) are not stored in the repository; they are recreated on the first build.
