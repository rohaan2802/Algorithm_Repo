Overview

Design and Analysis of Algorithms (CS-2009) at FAST-NUCES Islamabad, Fall 2025. The repository has 22 lectures, three assignments with my C++ solutions, the Merkle tree, treap and heap project, past papers, practice problems, two textbooks and my study notes.

Unit 1

Analysis

Asymptotic notation, recurrences, recursion trees and the master method.

Unit 2

Sorting

Insertion, merge, quick and heap sort, and counting and radix sort in linear time.

Unit 3

Strings & graphs

Naïve, Rabin–Karp, automata and KMP matching; BFS, DFS, MST, Dijkstra, Bellman–Ford, Floyd–Warshall.

Unit 4

Greedy & DP

Activity selection, Huffman codes, matrix-chain, 0/1 knapsack, rod cutting and LCS.

Get the Files

Clone everything with Git, or download the ZIP from the Live Links.

Clone the repository

Command
git clone https://github.com/rohaan2802/Algorithm_Repo.git

Build a C++ solution (any compiler)

Command
g++ -std=c++17 -O2 "Assignments/22i_2327_A3_Sec_D/Q_01_Sol/Source.cpp" -o q1 && ./q1

Each .sln file opens its project in Visual Studio (Desktop development with C++). Build output folders such as .vs, x64 and Debug are not stored; Visual Studio recreates them on the first build.
